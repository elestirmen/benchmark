# Model ağırlıkları

Benchmark varsayılan olarak bu klasördeki `.h5`, `.keras` ve `.hdf5` model
dosyalarını tarar. Model ağırlıkları üretilmiş ikili varlıklar olduğu için Git
deposuna dahil edilmez.

Mevcut çalışma alanında modeller özgün konumları korunarak
`template-matching/top_modeller` klasöründen buraya kopyalanmıştır. Yeni bir
klonda model dosyalarını bu klasöre yerleştirin veya çalıştırırken
`--model-dir <klasör>` verin.
